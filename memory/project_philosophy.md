  특정 에이전트의 개인 메모리만 알아야 이어갈 수 있는 구조를 피한다.

  경로 재편, 중복 제거, 출력 삭제는 영향과 근거를 확인한 별도 작업으로 다룬다.
- 결과는 저장 출력, 현재 환경 재실행, 외부 공개 상태를 구분한다.
  확인되지 않은 성능·수상·개인 기여·운영 상태를 문장으로 보완하지 않는다.

## 아직 정하지 않은 사항

- 공개 문서의 한국어/영어 구성과 목표 독자.
- 각 프로젝트의 대표 산출물, 수행 기간, 개인 기여, 수상 근거.
- 재현 환경을 어디까지 복원할지와 데이터 공개 범위.
- 기존 폴더명·파일명·체크포인트의 유지 또는 재편 범위.
- 다른 GitHub 저장소까지 확장할지 여부.

새로운 사용자 결정은 날짜와 근거를 붙여 추가한다. 제안을 사용자 확정 결정으로
바꿔 기록하지 않는다.

[추론] 기존 영어 README의 언어를 유지하면서, 루트는 포트폴리오 입구로,
네 프로젝트 README는 깊이 읽는 문서로 구성했다. 세 팀 프로젝트가 네 폴더에
나뉜 구조는 이름을 바꾸지 않고 설명과 상호 링크로 이해할 수 있게 했다.

채택한 표현 방식:

- 색을 통일한 SVG 표지, 프로젝트 번호, 탐색 링크, 요약 표와 읽기 순서를 사용한다.
- 실제 결과 그림은 저장된 원본을 그대로 보여주고, 장식 그래픽과 분석 그림을 구분한다.
- 개인 역할과 팀 성과를 구분하고 협업자의 원래 기여 기록을 남긴다.
- 이력서·회고 자료의 성과는 출처가 있는 보고 수치로 적고, 노트북 저장 지표와 섞지 않는다.
- 기간 차이, loss/accuracy 출력 문제, 표준화 오차, 평가 설계 한계는 근거와 함께 설명한다.
- 이력서 원본·연락처·개인 로컬 경로를 공개 자료로 복사하지 않는다.
- 실제 학습 재실행과 데이터 공개는 문서 작성과 별개다. 검증 없이 버전을 고정하거나
  성공한 재현으로 표시하지 않는다.

[팩트] 원본 프로젝트 자료를 이동·삭제·수정하지 않고 문서·표지·출처·ignore 규칙을
추가했다. 상세 결정과 미확인 항목은 최신 세션 기록과 근거표에 남겼다.
